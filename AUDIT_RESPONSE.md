# Audit disposition and retraining corrections

The detailed evidence remains in [`../audit/VGAE_RETRAINING_AUDIT.md`](../audit/VGAE_RETRAINING_AUDIT.md). The second-pass review confirmed every material audit conclusion. It corrected four points of precision, not the underlying findings:

- The encoder has four GINE trunk blocks, but only blocks 2–4 were residual.
- The integer negative-sampling bug usually made the candidate complement exhaustive; it was not necessarily newly random on every validation pass.
- KL was an explicit regularizer, although it had no schedule or calibrated weight.
- The recorded local DeepChem value was an image ID, not a registry digest.

## How this package addresses the findings

| Audited issue | Disposition | Retraining implementation |
|---|---|---|
| Batch integer passed as every graph's negative count; easy and hard sets duplicate | Confirmed, critical | Explicit CPU sampler computes ratios per graph, uses unique undirected edges, prohibits cross-graph/positive overlap, and makes easy and hard-pool sets disjoint. Hard mining is also per graph. |
| Fixed prefix and 10,002-step cap | Confirmed, critical | No prefix cap. Immutable shards are deterministically shuffled and cycled; `max_steps` is explicit and data-cycle progress is logged. |
| Every worker rescans the Arrow stream | Confirmed, critical | Feather record-batch ranges are assigned once to disjoint Slurm array tasks. Training ranks receive disjoint graph shards. |
| Worker/chunk-dependent split and unstable validation | Confirmed, critical | Canonicalize/deduplicate first; split by a seeded stable Bemis–Murcko scaffold hash. Both descriptor training and validation use `mu`; validation also uses fixed seeds, no adaptive hard negatives, and a separate test split. World size is checkpointed as part of exact reproducibility. |
| Scaler fitted on first 10M rows before filtering and split | Confirmed, critical | Streaming population statistics are fitted on all eligible, deduplicated **training** rows only and stored as named JSON arrays. |
| Descriptor names/provenance absent | Confirmed; descriptor identity/order now resolved | The owner supplied the original `getMolDescriptors` function. Its filtered `_descList` order was confirmed from dtypes/statistics and by recomputing one ZINC and one PubChem row: all 13 values matched at `1e-12`. `configs/descriptors.yaml` now binds every column to a name, unit, and RDKit callable. The original RDKit version remains unrecorded. |
| Stereochemistry dropped, arbitrary canonical positional encoding, limited element policy | Confirmed | Isomeric canonical SMILES and chirality/stereo features are retained. Position encoding is disabled by default. B and Si are supported by default; the exact element and fragment policy remains configurable and recorded. Lost source stereochemistry cannot be recovered. |
| Mutable DeepChem feature defaults | Confirmed risk | DeepChem is removed from the pipeline. A local explicit feature schema and its hash are embedded in graph shards and checkpoints. |
| Shortcut-prone reconstruction; only atom/bond prefixes decoded | Confirmed | Node and bond features are masked, bonds are dropped for denoising, all categorical/binary feature groups are decoded with group-appropriate losses, and the edge decoder is symmetric. |
| Mean-only graph pooling weak for extensive descriptors | Confirmed improvement opportunity | Descriptor head receives mean, sum, max, and log atom count. Validation reports every descriptor separately. |
| KL dominated old model selection; latent under-use | Confirmed | KL is computed as latent-sum/node-mean, scaled by `1/latent_dim` by default, warmed up, and log variance is clamped. Default latent width is reduced from 512 to 256; it still needs ablation against 64/128/512. |
| Checkpoints not resumable or self-identifying | Confirmed, critical | Atomic `last.pt`/`best.pt` contain model, optimizer, scheduler, AMP, all-rank RNG, all-rank data cursors, step, best score, world size, and hashes of config/data/features/scaler. Mismatches fail closed. |
| Direct checkpoint writes and rounded filenames | Confirmed | Temporary-file + `fsync` + atomic replace; stable names and exact metrics inside the checkpoint/log. |
| Old model described as a generator | Rejected as a capability claim | This remains a per-node variational molecular encoder with denoising reconstruction and descriptor heads. It is **not** a complete de novo graph generator. |

## New or remaining red flags

1. The descriptor blocker is resolved, but the source RDKit version was never recorded. The exact cross-source row checks substantially reduce this risk, and retraining pins RDKit 2025.9.3. `_descList` is an internal ordered list, so all downstream artifacts use the explicit fixed column mapping rather than rediscovering its order at runtime.
2. The corrected model is intentionally not checkpoint-compatible with the old weights. It must start from scratch; importing the old state would undo several corrections.
3. Hash-based scaffold groups keep related ring systems together, so observed split fractions will be close to, not exactly, 99/0.5/0.5 percent. Acyclic molecules use non-isomeric canonical SMILES as the fallback group key.
4. Duplicate molecules whose 13 descriptors disagree beyond configured tolerances are excluded and written to `work/conflicts/`. A high conflict fraction stops the pipeline.
5. The raw inputs appear to contain little or no stereo marking in the audited samples. Preserving stereo now cannot reconstruct information already removed upstream.
6. Precomputing roughly two hundred million graphs can consume hundreds of gigabytes to multiple terabytes. Confirm the project quota before the graph stage.
7. The GH200 node/GPU budgets are conservative defaults, not benchmarked optima. Run a short allocation first and tune node budget, array throttles, and wall times from measured throughput.
8. Reconstruction and descriptor losses do not establish transfer quality. Promotion now requires scaffold-held-out geometry, retrieval, clustering, and ten-split external frozen probes before any generally useful representation claim.
9. Arrhenius login/CPU nodes are amd64 while GH200 nodes and the training SIF are arm64. The login-side submission wrapper never executes the SIF; an arm64 orchestrator submits all container stages on GPU nodes. This is architecture-correct but consumes GPU allocation during CPU-heavy preprocessing. A separate amd64 preprocessing SIF is preferable if a matching `-cpu` allocation becomes available.
10. The first four-GPU launch exposed a DDP reducer failure: the edge decoders were called through `model.module` outside the DDP-visible `forward` path. The edge candidates and both decoder branches now run inside `forward`; hard negatives are selected from returned logits while gradients remain attached to selected logits. A two-rank regression test uses the production corruption/negative-sampling settings and requires gradients for every parameter.
11. Live GH200 telemetry showed only roughly 20–30% SM duty cycle, low power, and 8–11 GiB used per 96 GiB GPU. The input path had synchronous shard/batch construction, Python upper-triangle enumeration, unpinned transfers, one GPU `topk` launch per graph, repeated device-to-host mask checks, and an extra stop-signal collective every step. Training implementation version 3 replaced these with NumPy-vectorized deterministic candidate sampling, one segmented padded `topk`, pinned metadata/data transfers, deterministic one-batch look-ahead, device-side mask fallbacks, and bounded ten-step stop polling. Checkpoint cursors refer to the next unconsumed batch even when prefetch has advanced internally. Checkpoints also bind a separate effective training-plan hash; saved-model evaluation recovers the recorded effective plan. Four-GPU real-data training and held-out evaluation subsequently completed successfully.
12. CPU interrupted/resumed training is bitwise identical to uninterrupted training, including the next data cursor and stochastic streams. CUDA graph scatter/reduction kernels can differ at the last floating-point bits after a process restart even with identical saved state; the CUDA regression therefore checks the pinned DDP objective, gradients, and rank agreement rather than claiming cross-process bitwise determinism. This does not weaken atomic resume, but publications should describe GPU reproducibility as numerical rather than bitwise.
13. The first corrected full-corpus run exposed a new critical mismatch: training sent sampled `z` into a nonlinear mean/sum/max descriptor pool, while validation sent `mu`. The head learned a variance/noise-dependent representation that looked excellent on training batches but was discarded during validation. On 20,000 held-out graphs from the step-63,070 checkpoint, descriptor MSE was 0.977 from `mu` versus 0.071 from one posterior sample. Implementation v4 trains and evaluates descriptors exclusively from `mu`, adds a regression test for sampling invariance, rejects v3 checkpoint resume, and starts in a separate run directory. A fresh real-data v4 smoke run reduced deterministic held-out descriptor MSE from 0.299 at step 250 to 0.147 at step 1,000 while all 256 latent units remained active under an accelerated full-KL schedule. The 223,180,699 immutable graph artifacts remain valid and are reused.
14. Continuing v4 to step 55,000 showed that “active units” at early steps did not establish a useful molecular space. The count fell from 256 at step 15,000 to 91 in the 35,000 best checkpoint and 51 at step 55,000; median atom-mean variance fell from 0.0338 to 0.00385 while bond-feature validation worsened. More fundamentally, the model exposed only stochastic per-atom latents, not a canonical graph vector for the intended downstream use.
15. The v4 validation reducer multiplied every component by graph count. That is correct only for graph-mean descriptor losses, not masked-atom, corrupted-bond, sampled-pair, or per-node KL losses. Evaluation also disabled hard-negative construction. Implementation v5 carries exact numerator/denominator pairs through distributed reduction and reports easy and model-hard link AUROC/AP separately. The old JSONL is preserved but its scalar totals are forensic rather than authoritative.
16. Implementation v5 is a checkpoint-incompatible deterministic residual GINE encoder. It exports explicit clean `graph_z` and mean-node blocks and conditions every decoder on the graph vector. The selected objective uses mild mean-node NT-Xent (`0.01`) plus denoising/link reconstruction and a `0.5` descriptor auxiliary weight; the screened VICReg/projector and stochastic-KL alternatives are disabled. The public 384-dimensional vector concatenates both raw blocks, applies coordinate statistics fitted on 100,000 stratified **training-only** molecules, and weights the local block by three. Checkpoint, calibrator, graph/schema/config/plan identities are hash-bound and fail closed.
17. Representation claims now require a 10,000-molecule probe-training sample, 50,000 scaffold-validation molecules, 5,000 similarity queries, at least 10,000 recurring-scaffold clustering molecules, five KMeans seeds with 20 initializations each, and ten repeated scaffold splits on five external development datasets. Exported hashes are joined back to canonical SMILES; gates cover rank, robust topology accessibility, Morgan-neighbor recall/correlation, chemical and scaffold enrichment, clustering against a Morgan baseline, all seven downstream diagnostic feature panels, and frozen transfer. Large exports use efficient non-overlapping stratified windows. A second training seed, two independent 50,000-molecule validation samples, a 250,000-molecule internal test, an additional 37,225-molecule HIV scaffold benchmark, and Slurm job `1066977` with 43 tests plus clean two-rank CUDA/DDP validation provide replication evidence. Fail-closed promotion and the automatic checkpoint/calibrator export path have also been exercised on a GH200. The full diagnosis, artifacts, results, and limitations are recorded in [`REPRESENTATION_REPAIR.md`](REPRESENTATION_REPAIR.md).
18. A full primary-seed promotion sweep reran the identical 100k calibration, 10k/50k representation probe, 5k similarity-query, five-repeat clustering, and ten-split five-dataset downstream protocol at every retained checkpoint from 5k through 15k. All 105 protocol and artifact-integrity checks passed per checkpoint, but only step 10k passed all 17 quality gates. Step 5k failed effective rank and FreeSolv; 7.5k, 12.5k, and 15k failed only the frozen FreeSolv RMSE ceiling of 1.30. Step 15k reached 1.30346 and therefore remains rejected by the frozen fail-closed gate despite improving the other criteria. The versioned cross-step CSV, machine-readable audit, per-step compact probe/panel JSON, reproducible Slurm array, and audit summarizer preserve this selection evidence.
19. Three manuscript-revision audits were completed without retraining or pretrained-model execution. Serialized four-rank cursors show 57,504,265 unique training-graph presentations by step 10k and 86,236,032 by step 15k (26.00% and 38.99% of the training partition), so neither checkpoint completed one pass. Exact canonical-SMILES SHA-256 joins quantify pretraining-corpus overlap for BACE, BBBP, ESOL, FreeSolv, Lipophilicity, and HIV. A 13-descriptor-only downstream control reconstructs and hash-records the same outer and inner split identities and reuses the identical fold-local scaling, estimators, grids, and metrics. Descriptor-only RMSE was 0.8771 on ESOL, 1.6019 on FreeSolv, and 1.0071 on Lipophilicity versus gMolAI 0.7314, 1.2972, and 0.8125. The descriptors account descriptively for 83.2% and 71.9% of the mean gMolAI-versus-Morgan gap on ESOL and FreeSolv, but are worse than Morgan on Lipophilicity; causal attribution would require a retraining ablation, which was not performed. Git establishes that the validator was committed and unchanged before the expanded 5k-15k audit. Because the first commit already includes the original 10k selection and a preliminary retained-step screen, it does not establish prospective specification before those analyses. The evidence is tracked under [`artifacts/manuscript-rev3/`](artifacts/manuscript-rev3/).
